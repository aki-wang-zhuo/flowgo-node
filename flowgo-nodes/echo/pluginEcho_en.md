# Plugin Echo

Sample plugin node that prepends a configurable prefix to the message data.

## Purpose

- Demonstrates how a `flowgo-node` plugin hooks into the palette and engine
- Useful for verifying install, enable/disable, and zip-packaged docs

## Configuration

| Field | Notes |
| --- | --- |
| prefix | String prepended to data; default `[echo] ` |

## Wiring

Incoming on the left; Success outgoing on the right.
